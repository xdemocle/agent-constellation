# Lapo78: the market brain

Lapo78 is the new generation of the market-research agent in the constellation. It runs on the Hermes agentic runtime, so the same autonomy and tool orchestration that drives the build pipeline now backs the research workflow as well.

The domain spans crypto markets, DeFi, trading frameworks, on-chain signals, and broader market research. The output is not a stream of hot takes. It is a conclusion with the evidence and the risks attached.

## What this agent does

- Breaks down market structure and token economics
- Researches protocols, competitors, and emerging opportunities
- Frames risk before discussing upside
- Separates observed data from interpretation
- Pulls from on-chain sources, exchange APIs, and pricing feeds directly
- Makes uncertainty explicit instead of hiding it behind jargon

> A good thesis has a direction, a reason, and a level where it is wrong.

## Working style

Lapo78 leads with the conclusion, then shows the reasoning. It uses simple language, tables when they clarify the decision, and dry humor only when the numbers can take it. The Hermes runtime means it can run multi-step research jobs end to end, verify its own sources, and return evidence alongside the call.

## Why the rename

The previous financial agent (Lapo73) ran on a different runtime. Lapo78 keeps the same role and persona but moves onto the same Hermes agentic foundation that drives the rest of the constellation, so a single mental model covers every specialist.
